# v12 · 混搭 Plan B/C + 逐项精修

v12 不是一个一次性算出来的版本，而是用户对着 12 版横向对比图，
逐项指定「这一格用哪一版」之后，又对不满意的照片反复重选的结果。

## 基础混搭

| 来源 | 应用 |
|---|---|
| Plan B 照片 | DeepSeek Harness、ToDesk |
| Plan C 照片 | 哔哩哔哩、Edge、VS Code、飞书、PyCharm、互传 |
| v11 不变 | 微信、QQ音乐、Chrome、360、Cherry、WorkBuddy、WPS、录屏、百度网盘、网易邮箱 |

形状：除 QQ音乐（圆形 + 第一版金边）和 Clash Verge（圆形）外，全部圆角方形。

## 逐项精修（用户看效果图后提出）

### 1. 联想电脑管家 / 腾讯会议：表情呆板、配色不对

原图标都是高饱和纯蓝 + 白（blue 75~80% / white 20~25%），
旧照片背景偏暖、人物面无表情。

重新检索时把**背景蓝的权重提到 0.30**，并要求衣服白或浅蓝：

- 腾讯会议 → `c929b_90b313ea59.png`：浅蓝衬衫、亮蓝背景、开怀大笑
- 联想电脑管家 → `station_20260923_47687_2.jpg`：蓝色亮片西装、微笑、脸 650px

### 2. Clash Verge：小兔子粉装

用户指出 `fc2_src` 里有一套白兔帽 + 粉色衬衫的造型。
9 张同款全部渲染后逐张比对，选 `f2_0169.jpg`（正脸、粉衬衫、粉背景）。
因原图脸仅 122px，测试了 5 组裁剪参数，最终脸高 32% 最平衡。

### 3. 剪映专业版：黑白水手服

原图标 `black 75% / white 24%`。用户在 `forcharlie_picks` 里指出一套
白衬衫 + 黑领带的造型，正好对应。

**踩了两个坑：**

1. 第一版渲染把白衬衫染成了**电光蓝** —— 调色层为贴合黑白配色把饱和度推过头。
   其实照片本身已经是黑白，根本不需要调色，改为 `strength=0` 才修好。
2. 「剪映都不露脸」—— 检测发现 `fc_0639` 的人脸在**水平 76%** 位置，
   原裁剪的 `left` 被 clamp 限制，脸被挤到图标右边。改成**以人脸为原点裁剪、
   越界补边**，并把脸高目标提到 50%，面部才成为视觉核心。

最终选 `fc_0475.jpg`：黑 0.50 / 白 0.14，微笑看镜头，蓝污染 0.027。

### 4. Cursor：灰蓝纹理西装 + 眼镜

用户发来一张 832×572 的演唱会图，要求用这套服装。
按尺寸搜不到（图被重新编码过），改用「灰 + 蓝灰主导 + 横向 + 有脸」
在 398 张候选里定位到 `fc_0021.jpg`（灰 0.74 / 蓝灰 0.85），
但脸只有 92px。

按用户提示「这套服装应该不止一张」，用感知哈希在全库找同场景，
命中 **`station_0030.jpg`（3840×2160）** —— 同一姿势的高清原图，
脸 439px，清晰度提升 4.8 倍。最终以脸高 48% 渲染。

### 5. 腾讯QQ：豹纹装

用户先看中了「黑白为主 + 红色饰品」，试了 14 张后仍不满意；
随后指出 `fc2_src` 里豹纹夹克 + 猫耳那套更好，要求挑白色面积大的。

14 张豹纹同款全量测了白色占比，`f2_0069.jpg` 白色 0.159 最高、
猫耳完整、微笑，最终选它。

## 桌面校验

改完不能只看文件，必须验证 **Windows shell 实际渲染**：

```
python tools/check_desktop.py Cursor 剪映专业版 腾讯QQ QQ音乐
```

用 `SHGetImageList(SHIL_JUMBO)` 取 Explorer 内存中真正显示的 256px 图标，
与 `design_v12` 母版逐像素比对。判定用**中心区差异**（避开圆形四角背景）：

| APP | 全图差 | 中心区差 | 结论 |
|---|---|---|---|
| Cursor | 5.2 | 0.3 | 一致 |
| 剪映专业版 | 5.2 | 0.3 | 一致 |
| 腾讯QQ | 5.7 | 0.5 | 一致 |
| QQ音乐 | 17.4 | 0.4 | 一致（圆形四角） |
| Clash Verge | 17.5 | 0.4 | 一致（圆形四角） |
| 腾讯会议 | 8.2 | 0.3 | 一致 |
| 联想电脑管家 | 8.0 | 0.4 | 一致 |
