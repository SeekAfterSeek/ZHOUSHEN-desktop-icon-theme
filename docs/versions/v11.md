# v11 · 三标准加权 + 调色 + 唯一性

三条标准加权评分（配色相似度 34% + 衣服和谐 34% + 颜色齐全 20%
+ 脸够大 7% + 清晰度 5%），并加了三层关键改进：

1. 调色层 —— 实拍照片的配色不可能等于扁平 logo。Chrome 是红黄绿蓝四色，
   4800 张素材里一张四色齐全的都没有。解法是把照片色相/饱和/明暗掰向图标，
   同时用「人头保护椭圆」避免把头发染成绿色。
2. YuNet 人脸检测 —— 替换掉灾难性失败的肤色阈值法（检测框宽度达到 fw=1.00）。
3. 三重唯一性 —— 文件不重复 / pHash 距离 ≥10 / 连拍系列全局只一次。

审计结果：逐条颜色指令 24/24 通过，形状 IoU 1.00，真重复 0 对。
