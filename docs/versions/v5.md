# v5 · 异形图标 + 提亮

加入 5 种蒙版形状（squircle/circle/arch/pebble/blob）+ 外发光 + 星点。

用户反馈两个问题：
1. 「蒙了一层暗沉沉的遮罩」→ 亮度 ×1.16、饱和 ×1.28，去掉大面积压暗
2. 形状太多太杂

教训：有设计感和能看清人是对立的。异形后来被明确否决，最终只留方圆。
